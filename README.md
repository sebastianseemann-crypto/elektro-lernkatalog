# Lernkatalog Elektrotechnik

Lernmaterial zur Vorbereitung auf die Gesellenprüfung im Elektroniker-Handwerk,
Fachrichtung Energie- und Gebäudetechnik.

## Inhalt

| Seite | Datei |
|---|---|
| Fragenkatalog | `index.html` |
| Skript mit Zeichnungen | `skript.html` |
| VDE-Normenübersicht | `vde-normen.html` |

Der Fragenkatalog enthält selbst erstellte Übungsfragen mit je drei
Antwortmöglichkeiten, einer richtigen Antwort und einer Erklärung. Es sind
keine offiziellen Prüfungsfragen.

Alle Seiten sind eigenständige Dateien ohne externe Abhängigkeiten und
funktionieren nach dem Laden vollständig offline. Der Lernstand wird im
Browser gespeichert und kann als kurzer Text zwischen Geräten übertragen werden.

## Hinweis

Grenzwerte und Normangaben vor der Anwendung immer gegen die aktuelle Norm
beziehungsweise die Angaben des Netzbetreibers prüfen.
